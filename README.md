# Martin Kropp — Academic Homepage

Work in progress: migration of https://www.kropp.ch to GitHub Pages.

The first version is a lightweight Jekyll academic site with an al-folio-inspired design. The complete al-folio theme has **not yet been imported**.

## Content

- Homepage, teaching, research, publications, professional activities
- Markdown pages in `pages/`
- Legacy URLs preserved through permalink settings
- No domain change: www.kropp.ch remains on the existing host

## Deployment

GitHub Settings → Pages → Build and deployment → Deploy from a branch → main / (root).
