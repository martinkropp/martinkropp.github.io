## Current Courses

### [Software Engineering Fundamentals](https://swef1.pages.fhnw.ch/docs/swef-website/26HS/index.html)

Guided by the two fundamental principles that software engineering is an empirical discipline, where decisions are based on evidence, experimentation, and continuous feedback; and that software engineering is about developing and evolving software over time, this course introduces the fundamental principles and practices of professional software engineering. Students apply these principles through practical exercises in software design, clean code, testing, version control, and collaborative development, with an emphasis on quality, maintainability, and continuous improvement.

### [.NET Framework and C#](https://www.fhnw.ch/plattformen/ecnf/)

This course covers the core .NET architecture and runtime model (CLR), with an in-depth introduction to the C# programming language. It looks behind the scenes at the garbage collector, Intermediate Language, LINQ, lambda expressions and extension methods.

### [Software Testing and Quality Management](https://www.fhnw.ch/plattformen/stqm/)

Building on Software Construction, this course teaches advanced methods for building high-quality software and controlling and ensuring software quality with modern tools. Topics include distributed version control and workflows, acceptance testing, GUI testing, database testing, review techniques, quality assurance planning, technical debt, dependency management and traceability in software projects.

## Former Courses

### [Software Construction](https://www.fhnw.ch/plattformen/swc/)

This undergraduate course covered methods and tools for effective software development in the small. Topics included version control with Git, build automation, continuous integration, refactoring, unit testing, mock testing, metrics and simple code analysis — technical competences and tools needed for agile development.

### [.NET Enterprise Application Development](https://www.fhnw.ch/plattformen/dnead/)

This course built on .NET Framework and C# and covered technologies and frameworks for .NET enterprise applications: GUI development with WPF; web development with ASP.NET, MVVM, MVC and Silverlight; and database and service development with ADO.NET, Entity Framework, WCF and WF.

### [Software Engineering and Architectures](http://moodle.msengineering.ch/course/view.php?id=37) (Graduate)

This course in the MSE Master's programme covered advanced topics in software engineering and software architecture. I taught it with colleagues from Lucerne and Winterthur, covering software evolution, software analysis and visualisation.

### [Software Development Process](https://sgi.pages.fhnw.ch/moduluebersicht/2026hs/sepC/drehbuch.html) (2018)

This course offered a practical introduction to modern software development processes and project management, including agile development and the Scrum City Game, a Scrum simulation game. At that time, we played the game using paper, scissors, glue and coloured pencils – it was great fun.

### Mobile Application Development (2008)

This course provided a practical introduction to mobile application development, focusing on platforms, methods and technologies for building portable applications for mobile devices.

### Introduction into .NET (2008)

This course introduced .NET technology, covering the core base class library, architecture and frameworks such as WinForms, ADO.NET, ASP.NET and Web Services.

### Web Services Architecture (2007)

This course introduced the fundamental concepts of web services as an interoperable integration technology. Students applied and deepened their understanding of these concepts through practical programming exercises.

### Object-oriented Analysis and Design (2003–2005)

This course introduced object-oriented analysis and design based on Craig Larman's book *Applying UML and Patterns*.

### Software Engineering (1999–2003)

For several years I taught a thorough introduction to software engineering. During this course I also collected material, links and document templates for students.
